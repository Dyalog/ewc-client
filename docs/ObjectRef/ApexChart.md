# ApexChart

The EWC implementation of ApexChart supports:

| Properties|  |  |  |
|--|--|--|--|
 |   ChartType  |   Options  |  *SVG     |   Size      |
 |   Event      |   Posn     |   Series  |             |

\* indicates that the property can change after it has been set.
